# Implementation Plans (`docs/plans/`)

This directory contains formal, approved implementation plans written by the `planner` subagent (or `/plan` skill) before code is written by the `implementer` subagent (or `/implement` skill).

## Lifecycle
1. **Draft:** Created via `/plan` following `.agents/templates/plan-template.md`.
2. **Review:** Inspected against `CLAUDE.md`, layer boundaries, and acceptance criteria.
3. **Approved:** Marked `Status: APPROVED` by user or architect.
4. **Implementation:** Executed via `/implement` strictly following the steps.
5. **Completed:** All steps executed, unit tests passing offline, marked `Status: COMPLETED`.
